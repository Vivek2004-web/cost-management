# Project Rules - Auto GitHub Sync Directive

- **Automatic Git Sync**: Whenever any code, component, route, or styling changes are made in this repository, ALWAYS stage all modified files (`git add .`), commit with a descriptive message, and push immediately to GitHub (`git push origin main`).
- **Target Repository**: `git@github.com:Vivek2004-web/cost-management.git` (Branch: `main`).
